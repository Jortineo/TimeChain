A simple project made to solve a real life problem. It helps with gym sessions, studying, and anything where you would need a loop of several timers.

The core idea is that this app allows you to create a chain of timers that get executed one after another. For example, if i have a gym routine where i need to work for 45 seconds and then rest for 15, my regular phone timer doesn't cut it.

UI is made with PySide6.
